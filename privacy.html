Privacy Policy – CornelloTeam Bot

Terakhir diperbarui: 24 Oktober 2025

Dikelola oleh: CornelloTeam

1. Informasi yang Kami Kumpulkan

CornelloTeam Bot tidak mengumpulkan data pribadi pengguna secara langsung. Namun, bot dapat mengakses data publik dari Discord untuk menjalankan fungsinya, termasuk:

  • ID pengguna, ID server, ID channel
  • Pesan (hanya jika fitur moderasi atau log server diaktifkan)
  • Data hasil interaksi dengan perintah (command)

2. Penggunaan Data

Data digunakan semata-mata untuk:

  • Menjalankan dan memelihara fungsi bot
  • Menyimpan konfigurasi server (misalnya pengaturan prefix, level, role, dsb.)
  • Meningkatkan performa dan pengalaman pengguna

Kami tidak menjual, membagikan, atau menyewakan data pengguna ke pihak mana pun.

3. Penyimpanan dan Keamanan

Semua data disimpan secara aman di server yang dilindungi. Kami menerapkan langkah-langkah keamanan seperti token protection, enkripsi, dan autentikasi dua faktor (2FA) untuk mencegah akses tidak sah.

Data dapat dihapus secara otomatis jika bot dihapus dari server atau atas permintaan pengguna/server owner.

4. Hak Pengguna

Pengguna berhak untuk:

  • Meminta penghapusan data yang tersimpan terkait akun atau server mereka
  • Meminta penjelasan mengenai data apa saja yang disimpan oleh bot

Permintaan dapat dikirim melalui email ke support@cornelloteam.dev.

5. Perubahan Kebijakan

Kebijakan privasi ini dapat diperbarui sewaktu-waktu. Setiap pembaruan akan diumumkan melalui halaman ini atau server resmi CornelloTeam.

6. Kontak Kami

Jika kamu memiliki pertanyaan tentang kebijakan ini, silakan hubungi kami melalui:

  • 📧 Email: support@cornelloteam.dev
  • 🌐 Website: https://cornelloteam.github.io
